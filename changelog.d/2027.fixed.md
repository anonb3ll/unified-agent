- **`local-gate.sh --targeted` runs its pytest leg on macOS `/bin/bash` 3.2
  (#2027).** The targeted argument parser used `mapfile -d ''`, a bash 4.4
  builtin. On bash 3.2 the missing builtin left the argument array unset, the
  `set -u` error abandoned the pytest step, and the gate still printed PASS
  with no targeted test run. The parser now uses a bash 3.2-compatible
  NUL-delimited `read` loop. The gate also fails, and lists the leg as FAIL in
  the summary, whenever a requested full or targeted pytest leg never ran. A
  `--targeted` quoting error now shows the parser's own message.
