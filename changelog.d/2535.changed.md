- **One definition of "the verified caller is the human operator" at the
  approval gate.** `delegate()`'s human skip (and the server wrapper's matching
  human-delegation seam) matched only the operator's exact login label, while the
  operator self-approval pass accepted the label or an alias, case-insensitively.
  Both now call `config.verified_caller_is_operator()`, which reads only the
  transport-verified identity and takes no label, so it can never be applied to
  a self-claimed `from_agent` or `requested_by`. Visible change: a delegation
  from a verified operator alias no longer queues a second approval. An agent
  credential listed as an operator alias is still dropped from the aliases and
  gets neither pass.
