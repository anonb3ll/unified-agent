- **Dispatch temp files and node retirement edges (#2194).** Queue hygiene
  now also expires the `.<run_id><suffix>.<random>.tmp` files a crashed
  settings or sidecar write left in `dispatch-runs`, on the same retention
  window and with the same checks (regular files directly inside a real
  directory, symlinks never followed). A ua-node retired between its
  registration and the config sync that follows logs that at warning, not
  debug. The fleet console docs note that a node talking to a hub without the
  `node_retired` code falls back to the 5-minute auth retry.
