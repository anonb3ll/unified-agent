- **The component-map edge no longer marks tests unownable (#2652).** The declared edge that makes `components/__init__.py` depend on every module in the map is still followed for change reachability, but the selector now excludes it when computing unresolved tests. A dynamic import in a declared module was being carried through the components hub to every test that imports it, reporting 318 unresolved test files instead of 110 on the same tree. Selection for a real change is unchanged (324 files for a `tools/dash.py` change, 665 for a cross-cutting module).
