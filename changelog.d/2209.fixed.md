- **Worktree cleanup's in-use scan no longer slows quadratically on many
  `PATH=` words, and reads relative ones (#2209).** Every bare word of a `-c`
  or `env -S` string was looked up on every distinct `PATH=` value, and a
  wrapper carried every override into each command it ran: 2,000 of each took
  18-22 s of CPU, and a 131 KB string could take minutes. Overrides now feed
  one deduplicated list of at most 64 searched directories; a directory past
  that is kept as a live path itself, so a late `PATH=<worktree>/bin` still
  marks the checkout in use. 2,000 of each now take about 0.6 s, four times
  the cost of 500. A relative override entry (`env PATH=bin tool`,
  `PATH=../wt/bin`, an empty entry) is resolved against the process's cwd
  instead of being dropped. No path a process supplies (PATH entries,
  command-line path arguments, PYTHONPATH and VIRTUAL_ENV) is collapsed
  lexically any more: `<link>/../run.py` is looked up as the kernel resolves
  it, and its raw, normalized and resolved forms all count as live, so a
  checkout reached through a symlink is no longer read as idle. Resolution
  walks one component at a time like the kernel, following at most 40
  links, within a per-scan budget and without recursion. A path that cannot
  be resolved within those limits (a symlink loop, say), or whose lookup
  fails for a reason that does not prove it unused (ENAMETOOLONG from a long
  cwd, or a directory the hub may not search on the path of a process with
  the hub's own credentials, judged by the uid `ps` reports in the same row
  as the command line or by the /proc credentials), makes liveness unknown, naming the pid, so cleanup removes
  nothing rather than guess. A path component counts as unopenable only
  past 1,024 UTF-8 bytes (APFS allows 255 characters) or when the kernel
  rejects it as too long on a path shorter than PATH_MAX. A
  relative PYTHONPATH or VIRTUAL_ENV entry, which was ignored, is read
  against the process's cwd, and skipped when that is unknown. A process's
  own PATH gets the same cap: 500 bare words against a 3,750-entry PATH
  took 5.3 s, so 2,000 against 15,000 would take minutes; it now takes
  0.35 s. Its entries past the first 64 are kept as live paths, so a
  worktree directory late in the PATH still keeps its checkout.
