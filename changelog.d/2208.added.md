- **Operators can run node acceptance and retire from the Control Center and
  a shell (#2208).** The human operator's MCP profile is read-only, so device
  acceptance and node retire were out of the operator's reach. The Devices pane
  now lists ua-nodes with their stored acceptance state, **Run acceptance** and
  **Re-evaluate** buttons, **Retire** (a required reason and an in-page
  confirmation) and, on retired rows, **Unretire**; the hub's refusal (403 for
  a non-operator, 409 while work is queued) shows on the row. The new
  CSRF-gated `POST /api/action/node-retire` is the HTTP twin of
  `node_retire`/`node_unretire`, and `GET /api/nodes` lists retired rows under
  `retired_nodes`. `ua node acceptance start|evaluate|status [<node>]` and
  `ua node retire|unretire <node> --reason TEXT` call the same routes with the
  `ua` credential and support `--format json`.
