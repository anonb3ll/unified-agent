- **One command to add or remove an agent (#2453).** `unified-agent agent add
  <label> --office <id>` issues a bearer with its issue date, issuer and expiry
  on record, seats the label in its office with a profile and a local or cloud
  kind, prints the bearer once with the harness's hub entry, and reports the
  first heartbeat. The hub accepts it on the next request, with no `service.env`
  edit or restart. `unified-agent agent remove <label> --reason <text>` retires
  the label and revokes its credentials, and `unified-agent agent list` shows
  every agent's office, profile, kind, token dates and last-seen time. `add`
  needs `UA_MANAGED_SECRET_KEYS`, so the stored bearer is encrypted at rest,
  unless `--allow-plaintext-at-rest` is passed.
