- **CI runs tests in parallel and samples large parametrize matrices.** Each
  GitHub Actions pytest shard runs two pytest-xdist workers by default (now
  locked in the dev group); Cloud Build shards stay serial. Matrices in the redaction, JWK and audit test files with three or more
  dimensions and more than 32 cases run a
  pairwise-covering sample (every value pair still occurs), which cuts the
  collected suite from about 70,800 cases to about 27,000. Every case still
  runs when a change touches the redaction, JWK or audit scanners, their
  tests, the sampler or the dependency set, or with `--exhaustive` /
  `UA_TEST_EXHAUSTIVE=1`.
