- **The log redactor no longer slows quadratically on a run of tags shared by
  many `kty` names (#2203).** Text such as `kty: !<kty: !<...`, where each
  `!<` is cut short by a blank and so read as a tag, made every `kty` re-read
  the rest of the run: 1,000 repeats took 0.39 s of CPU and 4,000 took 6.1 s.
  The same happened with plain `!tag` and `&anchor` runs and no URI at all.
  The value scan now records where each run ends at every tag it crossed, so
  the run is read once. 4,000 repeats take about 0.02 s, and masking output is
  unchanged.
