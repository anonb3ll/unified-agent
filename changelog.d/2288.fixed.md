- **A remote executor no longer registers task worktrees in a repository above `~/dev` (#2288).** When the project's checkout under `~/dev` was missing, the executor searched upward for a `.git` directory past `~/dev`, so an enclosing repository (a dotfile repo in the home directory, for example) received the `git worktree add`. The search now stops below `~/dev`, and a re-rooted path with a `..` segment is refused. Without the checkout, `localize_worktree` returns no path and the canonical run is refused; it does not execute in the workspace root or in a repository above `~/dev`.
