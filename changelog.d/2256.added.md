- **URL-mode MCP approvals (#2256).** With `UA_ELICITATION_APPROVALS=1`, a
  client that declares URL elicitation on protocol 2026-07-28 or later, over a
  transport with an MCP session id, is offered a credential-free link to the
  Control Center approval page. Opening it authorizes nothing: the call waits
  on the server until a human resolves the approval row, then runs once. The
  challenge is bound to approval, session, caller, tool and arguments, expires
  after 15 minutes and is single-use. Without URL support the form path or the
  legacy approve-and-retry applies. No harness is verified for URL mode yet;
  see the capability matrix in `docs/mcp-client-capability-matrix.md`.
