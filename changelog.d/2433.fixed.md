- **Availability tests take their clock at call time (#2433).** `test_messaging_availability` stamped a "live" heartbeat with a module-level `datetime.now(UTC)`. A shard that imports the module minutes before running the test then read that heartbeat as `stale` against the real clock, so the two live-check tests failed on any slow shard (batch run 42735317617, shard 3, twice). The stamp now comes from `_clock()` inside the test.
