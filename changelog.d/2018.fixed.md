- **Pruning an expired tenant beacon no longer deletes a reused PID's fresh one
  (#2018).** The pruner checked a beacon's age and then deleted the file by
  name. A new process that reused the PID could publish its beacon in between,
  and the delete removed it. That process then stayed off the doctor's
  `tenant_consistency` row until its next 10-minute refresh. The pruner now
  renames the beacon to a unique tombstone and deletes it only if it is still
  the file judged expired. Otherwise it links the file back without
  overwriting a newer beacon. A tombstone left by a pruner that crashed is
  removed once it expires.
