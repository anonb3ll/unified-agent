- **`scripts/gate_route.py` reports how a merge should be verified (#2412).** Check receipts are keyed by git tree and environment, and a merge routes to reuse, targeted or full. Reuse needs the newest terminal full run on that exact tree and environment to have passed within seven days; cancelled, skipped and partial runs prove nothing, and unknown routes to full. The local gate records one receipt per leg on a clean tree. Report mode only: no gate changes, and DEPLOY-STEWARD tree equality stays the rule.
