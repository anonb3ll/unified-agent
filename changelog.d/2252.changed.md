- **Cloud CI runs on a self-stopping Spot VM by default (#2252).**
  `scripts/cloud-ci.sh` now executes `deploy/cloudbuild/ci.yaml` on a Spot
  `e2-highcpu-8` VM (`ua-ci-runner`). The VM starts for a run and powers off
  when its queue is empty. A run costs cents instead of about $0.50 of Cloud
  Build minutes. Statuses, supersession and `--reconcile` are unchanged.
  `UA_CI_BACKEND=cloudbuild` restores the previous backend.
