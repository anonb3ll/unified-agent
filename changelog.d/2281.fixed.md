- **Worktree cleanup tests no longer depend on the host's processes (#2281).** Tests now see an empty process table unless they supply their own (usually a `/proc` look-alike). A non-dumpable same-user process such as `ssh-agent` used to make liveness unknown, so cleanup retained everything and seven `test_worktree_policy.py` tests failed on such a host. One opt-in integration test still reads the real `/proc`: set `UA_TEST_REAL_PROC=1` on Linux to run it.
