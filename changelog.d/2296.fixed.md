- **The surfaces audit no longer fails on agent logs that hold no live key (#2296).**
  Codex keeps `~/.codex/memories` as its own local git repository, and newer
  Codex rollouts write records the transcript schema does not know, so their
  JWK-fixture findings were graded as source and failed `--fail-on high`
  every day. A memory or session file is now an agent log when its path and
  minted name match a known store and it is outside source control: outside
  git, untracked, or tracked only in a repository rooted at the store itself
  with no network remote. In that class a SECRETS-KEY finding stays HIGH only
  when its line holds live-looking key material (a bounded match with no
  stand-in wording, or a JWK private member with an opaque value); otherwise
  it is MEDIUM (LOW for the JWK heuristic in a schema-verified transcript, as
  before), so an over-long match across an embedded document no longer fails
  the gate. Repo source, `.env` files and credential stores are unchanged.
