- **A Codex CLI completion adapter, shipped disabled (#2026).** It covers ChatGPT
  subscription sign-in only, the provider's own model selection, private
  structured-response inputs, observed token metadata, a capacity backoff
  (including usage limits reported only on stderr) and model-pin exclusion. It
  accepts response schemas in JSON Schema 2020-12 only. Every request is refused
  with `tool_deny_all_unsupported` before any process is spawned, because the
  Codex CLI has no supported way to run with all tools denied (`codex exec` has
  no core-tool allow/deny switch and `apply_patch` cannot be disabled).
  Re-enabling it is a reviewed code change once the CLI supports a deny-all; no
  setting turns it on, and nothing routes to it yet.
