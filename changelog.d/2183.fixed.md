- **A conversation handoff always tells its creator that it created the task
  (#2183).** The reply's `created` followed the deduplicated handoff event, so a
  repeat by the same participant that read the claim result and wrote the event
  before the creator did made the creator's reply (and the recorded event) say
  `created: false`. Under load every caller of a concurrent group could be told
  so. `created` now follows the claim alone, and the creating call has its own
  event key. The live-state idle-poller test now waits on the poller's own
  progress instead of a 2 s wall-clock deadline.
