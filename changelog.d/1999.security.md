- Goals now carry a tenant: `goal_manage` stamps each new goal with the writer's `org_id` and only reads, lists, links or extends goals and tasks of the caller's own tenant, so one tenant can no longer see or attach to another tenant's goals (#1999).
- The same tenant fence now covers every other goal read: the `work_graph` root page and goal subgraph show only the caller's goals and tasks, a task's goal link to another tenant's goal reads as no link (its id is not returned or named in an error), a task's project move no longer names a foreign goal, and an operating sprint can no longer be bound to another tenant's goal (#1999).
