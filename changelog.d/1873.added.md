- **Opt-in wakes for idle agent sessions (#1873).** A session launched with
  `UA_WAKE=1` requests wakes (`wake: true`); once the operator grants that
  session (#2050), a ua-node running with
  `UA_NODE_WAKE=1` types the fixed line `You have N new hub messages; run
  message_inbox` into its idle, unfocused, unblocked herdr pane when
  `request`, `query`, `handoff` or reply-expected mail arrives. The hub
  applies the debounce, the 10-minute floor, the hourly cap and a breaker
  after three unread wakes, and returns only ids and counts
  (`POST /api/node/wake`, `/api/node/wake/receipt`). No message text reaches
  the keystrokes. New `system_doctor` row `agent_wake`.
