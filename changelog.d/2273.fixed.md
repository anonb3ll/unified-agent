- **Affected-test selection keeps the import edge inside a spawn call's
  `getattr` default (#2273).** Since #2243, a call through
  `getattr(subprocess, "run", default)` counted as a process spawn and its
  arguments were skipped, so a loader call written as the `default` no longer
  contributed its import edge and the tests reached through it could go
  unselected. The default argument is visited again.
