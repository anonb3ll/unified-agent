- **Read-only gateway allows are written as hourly rollups (#1922).** A
  read-only call's ALLOW decision is no longer one `agent.gateway.decision`
  row per call. It is counted in memory and written as one hashed
  `agent.gateway.decision.rollup` event per caller, tool, profile and hour,
  with `count`, `first_at`, `last_at` and the distinct argument digests. On the
  hub that removes most of the ~80k rows a day this channel was adding. Denies,
  errors, parked approvals and every mutating call are still one event per
  call. A crash can lose up to one bucket of read-only allow counts; tune with
  `UA_GATEWAY_COALESCE_BUCKET_S` or turn off with `UA_GATEWAY_COALESCE_READS=0`.
  `args_sha256` is now computed over the redacted arguments, so it cannot be
  used to confirm a guessed secret.
