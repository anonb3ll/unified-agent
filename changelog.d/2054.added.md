- **Typed error codes on MCP tool errors (#2054).** A `conflict` (stale revision,
  run or lease fence, claim held by another agent, lost claim race, claim-release
  mismatch) or `approval_required` refusal now carries `structuredContent`
  `{"code": ...}` (plus `approval_id` for an approval) next to the unchanged
  error text; other errors are unchanged. `ua` reads the code first and keeps
  the text match only as a deprecated fallback for older hubs, removed one
  release after this deploys.
