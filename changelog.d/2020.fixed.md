- **Five review follow-ups (#2020).** The session transcript queues one more
  history refresh when a reconnect or item event lands while a scan is still
  reading, so a checkpoint committed during a disconnect no longer stays hidden
  until the next refresh. An Approval Ledger re-request for a head whose
  approved pass outlived its TTL now expires that row and queues a replacement
  instead of answering `already_requested`. A re-request refused for a stale,
  closed or off-base head is now recorded on `agent.github_app.rerequested`
  with its outcome (`stale_head`, `not_open`, `wrong_base`), and so is one
  whose PR read from GitHub failed (`read_failed`) or whose GitHub
  credential could not be resolved (`token_unavailable`); a transcript scan that
  settles while the tab is hidden holds its follow-up refresh until the tab is
  visible again. The
  `tenant_consistency` doctor row on macOS resolves a relative hub `UA_HOME`
  against the LaunchAgent plist's `WorkingDirectory` instead of reporting
  UNKNOWN. An ACP agent's process group is no longer reported stopped when a
  member's `/proc` stat cannot be read (EACCES); only a vanished process counts
  as gone, and an unreadable process is placed by `getpgid`, so one in another
  group no longer keeps the group alive.
