- **The SDK for outside applications lives in `ua-rust` (#2726).** `ua-rust` `sdk/typescript`
  replaces the retired `unified-agent-sdk` repository, and this supersedes the #2380 note that
  made `packages/protocol` and `packages/client` the only SDK source: those packages are this
  repository's own TypeScript layer (the Control Center and in-repo clients), not the SDK that
  other applications consume. The `sdk/typescript` workspace is built from source and is not
  published to a registry yet. README, the docs index, interfaces, the launch guide, the
  architecture pages and the TypeScript ADR all point outside readers at
  `anonb3ll/ua-rust` → `sdk/typescript`.
