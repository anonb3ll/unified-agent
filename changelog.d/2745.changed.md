- **The public export's vocab gate now allows the shipped role names (#2745).**
  A fresh export tripped the gate on 1,325 hits, all of them the product's own
  operating-profile vocabulary (`steward`, `chief-of-staff`) plus three literal
  placeholders in a changelog fragment. The allowlist now covers those role
  names for the paths that carry them, so the gate exits 0 on a fresh export
  while still failing on a private host, home path or address. The `#2740`
  changelog fragment describes its placeholders instead of spelling them.
