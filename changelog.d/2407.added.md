- **A steward can now record a review read from a hub client (#2407).** `unified-agent-review record-read` on a host with no local store posts to the new `POST /api/review/reads`, so a completed read clears `unified-agent/review-head` without a shell on the hub. The hub takes the reader from the verified credential, keeps the live-head and delta-read refusals, and admits only humans and identities named in `UA_REVIEW_READERS`, which is empty by default.
