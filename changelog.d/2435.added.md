- **The requesting agent is told when its approval is decided (#2435).** After
  a human decides an approval, the requester gets one hub `inform` from the
  service sender `hub-approvals`, naming the approval and the decision (never
  the tool, its arguments or the reason). The message id is fixed per decision,
  so a redelivery is a duplicate. `hub-approvals` and `approval-receipt-` ids are
  reserved for the hub, like `hub-delivery`. `messaging.index.ANSWERED_BY` is now
  public.
- **A reply no longer defaults to the asker's stale session.** `reply_to` used to
  route a reply to the parent's `from_session` whenever that session had not
  ended. A session that is open but past `UA_SESSION_LIVE_MINUTES` (the asker
  restarted) now gets label mail instead, so the reply reaches the agent's live
  sessions rather than waiting on a dead one and dead-lettering. An explicit
  `to_session` still reaches a stale session.
