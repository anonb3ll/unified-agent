- **Interactive calls bound to their run (#2313).** Interactive (bearer and
  device sign-in) MCP calls are now bound to an evidence episode,
  `run:<run_id>`, when the caller holds exactly one live `doing` claim whose
  open self-pickup run is its own; any other caller stays unbound and is
  reported as unbound. `evidence_report` counts each self-pickup run as a run,
  so a denial during interactive work is listed against its task. Read-only
  allows in such a run still coalesce into rollups, and each rollup carries the
  run's episode. The session-credential episode is now built with
  `gateway.session_episode_id()`.
- **Episode caps count bearer runs (#2313).** `max_calls_per_episode` and
  `fatigue_band_cap` treat a `run:` episode as existing when the hub opened that
  self-pickup run, and count its calls from the gateway, including rolled-up and
  still-coalesced reads. `evidence_report` keeps every former claimant of a task
  (from its `selfpickup.claimed` events) in the denial window.
