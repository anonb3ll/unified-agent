- **`ua` covers the daily task and mail journey (#1937).** New explicit write
  verbs over the same authenticated hub gateway: `ua task add`, `task claim`,
  `task update`, `inbox read`, `inbox ack` and `inbox reply`. Input is strict
  JSON (flags, `--input`/`--json`, `@file` or stdin) validated against the live
  schema; identity always comes from the hub-verified credential. A stale
  revision or a claim held by another agent exits 8 with outcome `conflict`; a
  write parked for human approval exits 9 with outcome `approval_required` and
  its `approval_id`. Retry keys are offered only where the hub implements them
  (`task_add`/`task_update` `idempotency_key`, a reply's `message_id`). Mail
  bodies render as untrusted data, and a reply is sent only with an explicit
  recipient and body. `docs/cli-reference.md` now names the installed entry
  point `unified_agent.cli:entrypoint` (#1961).
