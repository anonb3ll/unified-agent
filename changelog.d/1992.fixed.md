- **Turn checkpoints stay bounded and complete (#1992).** A node now stops
  reading a turn's diff at 2 MiB and drops it (the transcript says "Diff too
  large to record") instead of holding the whole diff in memory or on disk. Old sessions' checkpoint refs are pruned by a sequence
  number recorded with each checkpoint, so sessions that checkpoint in the same
  second no longer lose a newer session's refs. A session transcript reloads
  its own turns, including their workspace changes, through a new `item_id`
  filter on `event_log_query` and `/api/events`, however many fleet events
  came after them. It shows the latest 5,000 events (history and live events
  together) plus the most recent workspace checkpoint, says so only when older
  events were left out, and refreshes by reading just the events after the
  last one it has, so a busy session no longer rereads its whole history on
  every update.
