- **CI on GCP Agent20 Build (#2115).** `scripts/cloud-ci.sh <pr|ref>` runs the
  gates, the four pytest shards and (when `packages/` changed) the js job for
  one exact commit on Cloud Build, using `deploy/cloudbuild/ci.yaml`. It posts
  the same commit-status contexts the review gate reads. It is used while
  GitHub-hosted Actions are refused and the Depot CI cap is reached.
