- **The security audit no longer flags editor snippet keys in vendored JSON
  Schemas as JWK private keys (#2222).** A key built by interpolation
  (`"${1:3000}": {`, as in VS Code `defaultSnippets`) may be a JWK type or a
  private member, so the YAML block reading of pretty-printed JSON reported
  its value as private member `"*"`, a HIGH `SECRETS-KEY` finding. Neither a
  type nor a private member holds a mapping, so a key whose value is a flow
  mapping is now an ordinary key; one holding a string or a sequence is
  still masked and reported.
