- **Affected-test selection (#2231).** `scripts/affected_tests.py` prints the test
  files a diff can affect, from a static import graph over `src/`, `tests/` and
  `scripts/` (imports, patch targets, path references, test helpers, directory
  conftests), plus the cross-cutting inventory tests that every change can break.
  It prints `ALL` when only the full suite can verify the diff; `--depth full`
  follows every lazy import. A selection is a targeted subset, never a
  certification: batch CI is still required.
  `./scripts/local-gate.sh --affected` runs that selection, and the review
  pipeline's targeted run now uses the graph's direct tier instead of
  `tests/test_<stem>.py` name matching alone.
