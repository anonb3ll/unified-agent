- **Turn checkpoints withhold edits inside a private key (#1990).** A turn's change summary now withholds a file's whole diff when its old or new content holds a private-key `BEGIN` marker, not only when the hunk shows that line. Editing one line in the middle of a key embedded in an ordinary file (for example a TLS key in `config.yaml`) no longer sends the surrounding key body lines to the hub.
