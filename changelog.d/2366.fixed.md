- **A comment between a JWK member name and its colon no longer hides the value (#2366).**
  A `//` comment (ended by LF, CRLF, CR, U+2028 or U+2029) and a block comment that is
  over 1024 characters or holds a quote, brace or colon are now read across on redaction,
  `private_members`, `check_secrets` and the public relay. The comment body is still
  scanned as prose, so nothing inside it stops being detected.
