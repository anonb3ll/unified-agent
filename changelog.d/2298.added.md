- **Node release roll is a script (#2298).** `scripts/node-release-roll.sh --sha <sha>` builds a release worktree, gates it on a side-effect-free import check (never `unified-agent --version`), swaps `~/.unified_agent/release/current` atomically, restarts `ua-node` (systemd) or `com.unified-agent.node` (launchd), and swaps back if the node does not stay up. `--check-only` reports the effective supervisor path, `--dry-run` writes nothing, and `--retire-stale [--yes]` removes old release worktrees but never the current or previous target. Rolls and retirements share one lock. A roll interrupted after the swap is rolled back, or recovered by the next run. Relative links resolve against their own directory, and a dirty release worktree is never reused. Idle worktree cleanup now also keeps the target of `release/current` and `release/previous`, whatever it is named. See `docs/deploy/node-release-roll.md`.
