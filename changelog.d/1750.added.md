- **Skills can be imported from Git with exact provenance (#1750).** New
  `skill_registry` actions `source_add`, `source_list`, `source_discover`,
  `source_refresh` and `source_import` pin a repository ref to a 40-character
  commit SHA, list its `SKILL.md` packages without checking out or running
  anything, and import a package as a reviewed registry version whose source is
  `git:<url>@<sha>:<path>`. Refresh reports the new SHA and a diff summary but
  never imports; the pin moves only on an explicit import. Nested packages,
  symlinks, unsafe paths and oversized packages are refused, and `file://`
  sources need `UA_SKILL_SOURCES_ALLOW_FILE=1`.
