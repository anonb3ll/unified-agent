- **Components load only when `UA_COMPONENTS` selects them (#2603).** Each manifest is imported by name at load time instead of through a static import block, `server.py` imports the non-kernel modules it needs at the call site behind a component check, and a kernel-only process registers exactly the kernel's and the adapter's tools. `/healthz` and `/readyz` stay always-on: they are registered from the adapter when Control Center is not loaded, so a partial hub still passes a deployment health check. The component map now supplies the edge a conditional load used to hide: `check_components` reads the same declared modules `affected_tests` does, so a change to `tools/dash.py` still selects 322 test files instead of 123. A map that cannot be read fails closed by declaring every module.
