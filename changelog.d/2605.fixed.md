- **Public export: a refusal instead of a wrong verdict (#2605).** The export
  script reads `policy.toml`, `replacements.toml`, `denylist.toml` and
  `exclude.txt` from disk, not from `--ref`, so a stale checkout applied one
  tree's rules to another tree's files: `--ref 8a6bed27` from a checkout at
  640d9c0e reported 30 secret findings for the tree that is clean from a
  checkout at 8a6bed27. A ref export now compares the four files it actually
  loads against that ref's blobs and refuses, naming the file, before writing
  anything, including when `--src` names a different checkout from the one
  running the script. Previews that read the working tree are unaffected, as is
  a source tree that carries no anonymity config.
