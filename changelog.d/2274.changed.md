- **The review pipeline's own test selection is red tier (#2274).** `reviewer.py`
  asks `affected_tests.select()` which tests to run against a pull request's
  diff, and `scripts/local-gate.sh --affected` reads the same module, so a PR
  that narrowed the selection would have been choosing the evidence for its own
  review without escalation. `src/unified_agent/affected_tests.py` and
  `scripts/affected_tests.py` now match `RED_TIER_PATTERNS`, as does
  `cycle_eligibility.py` itself, which decides what escalates at all.
  `tests/test_affected_tests.py` is deliberately not affected.
