- **Web CI failures are no longer masked (#2166).** Cloud CI's web step runs
  as one AND-list, so a failed Vitest run or web build can no longer be hidden
  by the exit status of the Playwright line that followed it, and Playwright no
  longer starts against a missing build. Web tests wait up to 5s for lazily
  loaded panes, which a loaded runner can take longer than Testing Library's
  1s default to transform on first import.
