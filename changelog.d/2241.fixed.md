- **The Depot CI copy honours the pytest worker count (#2241).** Its dispatch
  input `pytest_workers` and the `UA_CI_PYTEST_WORKERS` variable were declared
  but never reached pytest, so Depot shards always ran serially. They now pick
  the xdist worker count by the same rule as the GitHub copy: two workers by
  default, the input or variable overriding it, and `0` running serially.
