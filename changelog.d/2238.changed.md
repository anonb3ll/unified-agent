- **Stateful tests start from a template store (#2238).** The autouse
  `isolated_env` fixture copies an already-initialized `memory.db` into each
  test's home before `init_db`, which still runs every schema script, migration
  and post-init hook. Store setup drops from about three seconds per test to
  under a tenth of one; a 77-test memory sample went from 181 s to 45 s.
  `UA_TEST_FRESH_STORE=1` builds every store from scratch.
