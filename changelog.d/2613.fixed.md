- **Spot CI no longer starts a run the VM's 3-hour cap would cut off (#2613).** GCE counts the cap from VM start, so the third back-to-back run was stopped mid-way and redone. The VM now starts a run only in the first 15 minutes after boot; otherwise it powers off with the run still queued and the watcher's next status poll restarts it with a fresh window. That fits the slowest measured run, a ~135-minute exhaustive one, with about 30 minutes to spare.
