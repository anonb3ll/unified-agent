- **Interactive usage reports stay complete across a resumed session (#2037).** When a Claude Code session claims a task, is superseded by another claim, and later renews the first run, the usage hook now reports every window that run was open, so its recorded tokens are the total, not only the latest stretch. Authenticated `task_claim` replies and unkeyed `task_update` replies now include `verified_caller`, the caller's own label, and the hook uses it to remember only this session's own runs, so a teammate's claim can no longer cut this session's window short. Hook state for sessions that can no longer resume is deleted after 30 days. `ua-usage` accepts repeated `--window START,END` to measure several disjoint windows at once, and refuses overlapping ones so no call is counted twice.
