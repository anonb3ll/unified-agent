- **The GCP control-plane hub unit drains before a restart (#2270).**
  `ua-hub.service` no longer runs `docker rm -f ua-hub` on every start, which
  SIGKILLed a leftover hub container with requests in flight; it stops the
  container with the same 30 s grace as `ExecStop` and then removes it.
  `ua-hub.service` and `ua-hub-backup.service` also gain systemd hardening
  (`NoNewPrivileges`, `PrivateTmp`, `ProtectSystem=full`, kernel and cgroup
  protections) that keeps the docker socket, the data disk and gcloud's config
  under `/root` writable.
