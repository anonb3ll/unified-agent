- `system_doctor` has a `package_checkout` row that is DEGRADED when the running `unified_agent` is imported from a per-task worktree (`.worktrees/*` or `.claude/worktrees/*`), or when the main checkout's shared `.venv` editable install (a `.pth` path or a setuptools finder) resolves outside the main checkout's `src`. Without it, services using that venv silently run stale code (#1944).
