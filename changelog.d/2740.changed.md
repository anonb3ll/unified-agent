- **The public export gets a vocab gate and an allowlist (#2740).** ua-rust's
  `scripts/vocab-check.sh` now runs against an export through
  `scripts/public_release/vocab_gate.sh`, which copies the checker and this
  repo's `vocab-allowlist.txt` into the export, runs them there and removes
  both. It refuses rather than overwrite a checker or allowlist the export
  already has, and removes only the files it created. The allowlist covers
  intended placeholders only: home-directory example paths, shared-address-space
  SSRF fixtures, example tailnet host names and relative import paths. The
  product's role vocabulary (`steward`, `chief-of-staff`, `cloud-vault-steward`)
  is product content, so it is allowlisted for the paths that carry it rather
  than scrubbed.
