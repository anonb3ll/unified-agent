- **Abandoned claims, lapsed executor leases and stalled runs now recover
  without a restart (#1916).** Queue hygiene releases a task again when it was
  released once, claimed again and abandoned again. Before, the first release's
  marker blocked every later one. The Active Executor now reclaims its own
  expired locks every `UA_EXECUTOR_RECLAIM_INTERVAL_S` (default 300s), not only
  at startup. It also stops a child that has written no output for
  `UA_EXECUTOR_STALL_TIMEOUT_S` (default 1800s) and retries it with a backoff
  capped at `UA_EXECUTOR_BACKOFF_CAP_S`. A dispatch run that finished while
  its task-done write was lost is now closed by the next queue-hygiene pass,
  and the run's superseding-run check runs in the same transaction as its
  terminal write.
