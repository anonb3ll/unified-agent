- **`system_doctor` reports ua-nodes running a different commit than the hub
  (#1946).** A ua-node now reports the HEAD of the checkout it was imported
  from (`code_sha`, read from `.git` files once per process, null for a non-git
  install) at registration and, to a hub that advertises `node_code_sha`, on
  heartbeats. The new `fleet_node_versions` row is LIVE when every live node
  matches the hub's commit, DEGRADED naming each node that differs with its
  short SHA, and UNKNOWN for a live node that reports no SHA.
