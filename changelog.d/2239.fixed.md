- **A JWK in comment prose with a plain type and an identity-escaped key is masked (#2239).** In `#`, `//` and orphan-quote comment bodies, a key such as `"\d\p"`, with or without a trailing line continuation, is read with JS escape rules (it names `dp`), and the object's last `kty` decides whether it is private. A name private only for RSA stays public in an EC key.
