- **JWK and PEM redaction follow-ups from the PR #1146 review (#2019).** An unbalanced quote before or inside a JSON Web Key no longer hides its private members from the context scan, and a Python 2 or bytes repr (`u'oct'`, `b'oct'`) is read as one too. The no-context fallback now also catches a symmetric key's `k`. Less over-redaction: an apostrophe (`Here's`, `that's`) no longer opens a string that swallows the prose up to the next one, the RSA-only names `p`, `q`, `dp`, `dq` and `qi` are redacted only when `kty` is `RSA`, and a 4, 8 or 12 letter word that opens prose after a full unpadded PEM or PuTTY line is no longer read as the key's last line.
