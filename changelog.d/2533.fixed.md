- **Control Center no longer moves focus away from a field you are already typing in (#2533).**
  After a navigation, the shell moves focus to the new page's heading on the
  next frame. On a busy machine that frame could arrive after you had clicked
  a field and started typing, so focus jumped to the heading and the rest of
  the text and the Enter went nowhere (for example, creating a task with `c`).
  If focus has already moved into the page, the shell now leaves it there.
