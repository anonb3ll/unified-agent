- **Merge receipt v1 (#2307).** `unified-agent evidence receipt --pr <n>` renders
  `receipt.json` (`merge_receipt/1`) for one merged PR from hub records and GitHub,
  bound to the one task whose `evidence_ref` carries the exact PR URL; a missing or
  ambiguous binding is refused and `--task` only asserts it. Every null is
  explained in `omitted[]` (and nothing populated is), ticks appear only on rows a
  third party can check, authority counts only records for this repo, PR and head,
  a missing approval reads `not-recorded`, a missing review read is a finding, and
  ledger rows are referenced by hash with payloads withheld.
  `unified-agent evidence verify receipt.json` runs offline consistency checks and
  states what it cannot verify (authorship, ledger-head membership, row hashes).
