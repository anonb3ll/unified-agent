- **The evidence ledger refuses rewrites and reports rows written around it
  (#1908).** `event_log` now has append-only triggers: a raw `UPDATE` or
  `DELETE` aborts, and `prune_events` is the only sanctioned rewrite.
  `event_log_verify` reports `tampered` (reason
  `unhashed_row_after_chain_start`, with the offending row ids) when an unhashed
  row appears after the chain started, where it used to skip the row and report
  `valid`; unhashed rows before the chain started are still allowed and counted.
  A hub that ran `UA_EDITION=core` between enterprise runs will now see those
  rows reported. No agent tool can write under `Logs/audit-ledger-heads/` any
  more, `vault_write(force=True)` and `vault_move` included; only the re-anchor
  job writes the chain-head witnesses there.
- **Approval resolutions are recorded on the hash chain (#1909).** Approve,
  deny and revoke append an `agent.approval.resolved` event (approval id,
  decision, resolver identity, request payload hash, timestamp) in the same
  transaction as the status change, so a resolution can no longer commit without
  its ledger record.
