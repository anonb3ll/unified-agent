- **Hub-written tasks and memory notes record the caller's machine (#1633).** `source_host` used to be the hub's own hostname for every row written over the hub, because nothing set the request-scoped host. The auth middleware now binds it from the verified identity's `UA_AGENT_HOSTS` entry, the operator's binding; with no entry, or `label:hub`, it stays the hub's host. Request headers, the `heartbeat` tool's `host` argument and self-chosen ua-node names are never read for it. Requests read an in-memory snapshot of the binding, built at startup and refreshed in a background thread, so no request does file or database I/O for it. The binding ends with the request, so background work the request spawned stamps the hub afterwards. `config.current_source_host()` now always means the machine the process runs on; row stamps use `config.write_source_host()`.
