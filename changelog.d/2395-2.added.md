- **One writer releases a lapsed claim, and only on a recorded end (#2395).** Queue hygiene and the doctor's stale-lock reclaim both go through `lease_reaper`, which probes the owner first. A `doing` task goes back to `open` only when its owner's run is recorded as over (a failed or released self-pickup end, a cancel request, a failed dispatch run or executor attempt, each from this claim) or the owner has no agent row and no node. An active or unknown owner keeps the claim; unknown ones are listed under `leases_kept` and turn the doctor's `stale_task_locks` check DEGRADED. A done or cancelled task is never touched, so it keeps who closed it.
