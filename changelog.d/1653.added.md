- **Approval requests name the run that is waiting (#1653).** A new
  approval stores the verified caller's current run when that run is
  unambiguous: the claimed task's open run, or otherwise that identity's
  one live dispatch run. The queue, the approval detail and the request
  event include `run_id` so Inbox and Runs can link them. A request outside
  a run, or one whose run is ambiguous, stores null. Resolving an approval
  ignores `run_id`; it is display linkage only.
