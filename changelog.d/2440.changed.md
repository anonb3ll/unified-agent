- **Pull requests run the registry and inventory tests.** The `gates` job now
  runs the files and node ids in `tests/pr_inventory_tier.txt` on every pull
  request (about a minute), so a table with no tenancy class, an export import
  reference or a `layers.toml` placement that is missing fails the PR instead
  of the merge batch. The step also runs `scripts/check_components.py` once
  that file exists.
