- **Reproducible public export (#1849).** `scripts/public_release/export_public_tree.py`
  builds the anonymized single-commit tree from a git ref (default `HEAD`) rather
  than the working tree. The same ref and configuration give a byte-identical tree
  and, with `--init-git`, the same commit SHA. Each run writes a JSON and Markdown
  manifest of changed, renamed and removed files, rule hits and flagged ambiguous
  matches. `--verify DIR` fails on any denylisted identifier or unreviewed secret.
  The rules live in reviewed, versioned config (`policy.toml` and its siblings).
