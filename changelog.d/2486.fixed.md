- **pr-watch no longer reads healthy over a repository it stopped watching
  (#2486).** The run record cut the skip list to five and lost the count, and a
  tick that ran only the Approval Ledger poll cleared the list, so a repository
  that had timed out read as healthy before anything retried it. The record now
  keeps a `journal` and a `connector` section, and a pass that did not run
  keeps its state. A skip stays until a later journal pass reads that
  repository, `skipped_total` carries the full count, and `pr_watch_job` reads
  `DEGRADED` while a skip is unresolved or while either pass failed the last
  time it ran. `github_approval_backlog` is judged on the connector poll alone,
  so a skipped journal repository does not mark the ledger as stalled. Records
  written before the split still read.
