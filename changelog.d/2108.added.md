- **Railway deploy surface for a hosted hub (#2108).** The image now builds on
  Railway: the `VOLUME` instruction that failed both earlier deploys is removed.
  `.railway/railway.ts` defines the service, its `/data` volume, the healthcheck
  and the restart policy as a named IaC partial. A hosted start never prints the
  bootstrap token, and platform variables outrank the volume's `service.env`.
  It refuses to start without a volume, binds `PORT`, and allows the Railway
  domains and the healthcheck host. It drops from root to uid 10001 when Railway
  runs it as root. Runbook: `docs/deploy/railway.md`.
