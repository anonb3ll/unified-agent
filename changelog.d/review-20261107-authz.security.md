- **Delegation lifecycle actions require the caller's own identity.** `claim`, `release`, `cancel`, `fail`, `complete` and `retry` now refuse an `agent` that is not the verified caller (or an allowlisted alias), the rule `task_claim` already applies, so an authenticated agent can no longer drive another agent's delegation by naming it. `fail` and `complete` also act only for the delegator or assignee, and `retry` only for the assignee. Unauthenticated stdio keeps the claimed label.
- **`memory_restore` and the consolidate CLI restore take the supersede owner rule.** Only the note's author or a verified human can re-promote a superseded note, checked inside the write transaction, matching `apply_supersede`.
