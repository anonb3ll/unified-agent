- **Phone alert when an approval is waiting (#1988).** Set
  `UA_APPROVAL_PUSH_URL` to an `https://` ntfy topic URL (and optionally
  `UA_APPROVAL_PUSH_TOKEN`) and the hub pushes "Approval waiting (N pending)"
  with a link to the Approvals pane when a request is queued, at most once per
  30 seconds. Off by default. The alert never carries the request's contents,
  and the URL and token never appear in logs or `system_doctor`, which reports
  `approval_push` with the push host only.
