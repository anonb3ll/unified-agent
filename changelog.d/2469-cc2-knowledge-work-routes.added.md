- **Control Center v2 hub routes for knowledge and work (task #2469).** The web Control Center can now read a full memory note (`GET /api/memory/note`), list a vault directory (`GET /api/vault/list`), read a note's links (`GET /api/vault/links`) and a joint plan (`GET /api/plans/{plan_id}/joint`), and write memory notes (save, delete, restore, promote, feedback), vault notes and journal entries, plans (one route per `plan_manage` action, including the joint actions), task claims, task deletes and session ends. `POST /api/action/task` accepts `archived`, and `GET /api/whoami` reports the tenant `org` and `org_mode`. Each route calls the registered tool, so its policy, approval and rate-limit gates still run; identity arguments come from the signed-in identity. Shapes are in `docs/control-center-api.md`.
