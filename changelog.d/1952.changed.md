- **`memory_get` and `memory_search` label recalled notes as untrusted (#1952).** The note returned by `memory_get`, and each hit in `memory_search` `results`, now carries the same additive `trust: {level: "untrusted", source: "memory", author, note}` field that #1911 put on agent messages and vault inbox reads. Every note is labelled, including the caller's own: a note's `author` is a claim, an unverified stdio save may name anyone, and a peer's append keeps the owner's `author`, so no stored field proves who wrote the text. Existing keys and the result shape are unchanged. The field tells the reading model the text is data, not instructions; it does not alter the text.
