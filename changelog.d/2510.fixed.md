- **A retried Start no longer creates a second task.** The Control Center's
  launch guard dropped a launch's attempt id after a plain refusal (400), when
  the hub's attempt lookup said `failed`, and whenever the person chose
  "Launch again", so the next Start went out under a new id and the hub
  started a second task. The attempt id now stays, stored with a fingerprint
  of its request, until the launch is settled: the hub says it started, has
  no record of it, or failed before creating anything, or the person
  explicitly chooses "Start something new". A launch the person sends again
  survives a reload, is sent only with the same request, and the hub
  continues it instead of starting another. A lookup that cannot be read,
  the hub's new `unsettled` answer, and a team restore's `unknown` (the hub
  keeps no attempt for restores) no longer count as "not started".
