- **Operators can attest pending device acceptance runs from the Control Center
  and `ua node` (#2299).** `POST /api/action/node-acceptance` already supported
  `action: "attest"`, but neither `ua` nor the Devices pane exposed it, leaving
  read-only human operators without a UI or CLI button to finish the 15-minute
  attestation window after all five diagnostics passed. Added
  `ua node acceptance attest <node> --run-id <run_id> --evidence-ref <text>` and
  an inline **Attest** confirmation on **Devices → ua-nodes** (enabled only when
  a run is `pending` with all checks passing), preserving CSRF, inline 403/409
  refusals, and 202 approval-queue payloads.
