- **Local pytest runs can be signed before a pull request (#1355).** An agent
  signs the outcome and the test list as an in-toto attestation with the
  Ed25519 key in `UA_TEST_ATTESTATION_KEY`. CI checks that signature with
  `UA_TEST_ATTESTATION_PUBLIC_KEY` and re-runs a deterministic sample of the
  attested tests. A changed outcome or test list fails verification. Keys stay
  in the environment.
