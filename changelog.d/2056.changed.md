- **Control Center write routes return the typed error code (#2056).** A typed
  refusal on an `/api` write now answers `{"error", "code"}` like the MCP
  `structuredContent`: a `conflict` is always HTTP 409, a parked approval is
  always a 202 with `approval_id` and `"code": "approval_required"` (including
  approvals that previously surfaced as a generic 400, and team-boot autonomy
  pauses), and untyped errors keep their status with no code. `project_build`
  on a spec claimed by another agent is now a typed `conflict`.
