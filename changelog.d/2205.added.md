- **Re-attach Cloud Build CI to an existing build (#2205).**
  `scripts/cloud-ci.sh --reconcile <build-id> <pr-number | branch | sha>`
  settles the commit statuses of a build an interrupted watcher left at
  `error`, without submitting another build. It refuses a build whose
  `_SOURCE_SHA` is not the resolved head, and refuses when a newer run has
  since written any of the contexts, so an older result never overwrites a
  newer one. It waits for an unfinished build with the usual deadlines. An
  interrupted watcher now prints this command.
