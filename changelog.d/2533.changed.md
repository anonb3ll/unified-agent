- **CI runs on Depot CI.** GitHub-hosted Actions refused jobs over account
  billing, so pull-request gates, the merge queue, the nightly full suite and
  the post-merge Docker and install gates now trigger from `.depot/workflows/`.
  The GitHub copies are dispatch-only. Pytest shards and the Rust job run on
  8-vCPU sandboxes, the web accessibility gate on 16 and the SDK on 4, with one
  pytest-xdist worker per core. Dispatch a batch with `depot ci dispatch`;
  `docs/ci-batch-verify.md` lists the status, logs, diagnose, retry, SSH and
  metrics commands.
