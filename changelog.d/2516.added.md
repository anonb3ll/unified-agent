- **Control Center hub gaps for Runs, Work and Settings (#2516).** Plan create,
  routine create, workflow run, graph run, cycle start and session-credential
  revoke accept an `Idempotency-Key` under one scheme: same key and body replays
  the first answer, a different body is 409, and a start whose outcome is unknown
  is never run again. New reads: `GET /api/tasks/{id}/subtree` (every
  descendant), `GET /api/langgraph/runs/{run_id}` (progress from checkpoints),
  `GET /api/session-credentials` (operator, metadata only). `/api/evidence` pages
  by `cursor`, and `GET /api/evidence/export` streams the complete CSV or PDF.
