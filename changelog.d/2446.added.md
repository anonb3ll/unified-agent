- **Claude Code on the web joins the hub as `agent-cloud-agent1` (#2443, #2446).**
  `agent-cloud-agent1` is now a cloud-hosted identity with the developer profile: it
  claims tasks, messages, saves memory, journals and records evidence on the
  real hub, while the hub's disk, the Control Center, merge, deploy, approvals
  and credential tools stay closed to it. The cloud setup script registers the
  hub over HTTPS with an OAuth client-credentials grant
  (`scripts/cloud_hub_client.py` as Claude Code's `headersHelper`, so no token
  is stored) when the environment is configured and the hub answers as
  `agent-cloud-agent1`, and falls back to the stdio test fixture with a one-line
  notice otherwise. `python3 scripts/cloud_hub_client.py status` tells a
  session which mode it is in. Operator steps are in `docs/cloud-sessions.md`.
