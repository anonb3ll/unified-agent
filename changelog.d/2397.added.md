- **Agent-authored session handoff (#2397).** A session's owner writes a handoff note (`done` and `next_steps` required) that persists as a draft and commits when sealed; recovery reads only sealed notes. Per session: one pending note, a 5-minute cooldown, 5 per hour. Session packets now carry the sealed note, the context epoch (advanced on compaction) and a trust tier per section (T0 operator, T1 hub state, T2 agent prose). Quota failover to a live office peer is built; its hub-side trigger lands with the node receipt path. Failover keeps assignment, delivery and acknowledgement apart: a note whose transport did not confirm is `assigned` and can be failed over again, `delivered` means the transport accepted it or the receiver called `session_handoff_ack`.
