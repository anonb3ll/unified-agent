- **Agent pause and terminate fail closed without their stop handlers.**
  `agent_lifecycle` no longer imports `dispatch.coordinator` or `node_queue`;
  those modules register its `dispatch` and `node` stop handlers when imported,
  and the hub loads both through `webui.routes`. A process that has not
  registered every handler in `REQUIRED_STOP_HANDLERS` now refuses a pause or
  terminate with an error, before recording anything, instead of changing the
  state without cancelling the agent's dispatch runs and node items. In the hub
  the cancels run exactly as before. The layer-check baseline is now empty
  (task #1723).
