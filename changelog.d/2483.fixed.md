- **A lease whose run is recorded as ended is no longer renewed (#2483).**
  Queue hygiene renews lapsed leases before it reaps them, and it renewed any
  claim whose label had been active recently. The same label working on
  something else could therefore extend a claim whose own run had ended, which
  hid it from the reaper. Renewal now asks the owner probe about the claim
  itself and skips one that reads terminal.
