- **Each component declares its own MCP tools.** A manifest per component in
  `src/unified_agent/components/` lists the tools that component registers,
  and `server.py` composes the registry from them instead of naming about 200
  functions in one tuple. Adding a tool is one line in its component's
  manifest. Same tools, schemas, annotations and policy guard; `tools/list`
  now returns them in component order. The table of tools per component is in
  `docs/architecture/components.md` ("Manifests").
