- **Review reads are recorded for the release preflight's head-moved gate
  (#2294).** The gate added in #2259 had no writers, so it always answered
  `no-read-recorded`. A `validated` review verdict now records a `policy` read
  (only when the PR's live head is the validated head; a skip says whether the
  head moved or the lookup failed), and the new `unified-agent-review
  record-read` records an explicit `steward-read`, `human` or `delta-read`. An
  Approval Ledger approval records no read: an approval is not a read of an
  unread red-tier delta. A delta read is refused unless a full read is recorded
  at its `from_sha`, the base is an ancestor, the compare is not truncated and
  its files cover every red-tier path; the gate re-checks all of it and never
  uses a delta read as the base for a later push.
