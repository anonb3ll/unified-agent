- **An uncertain Approval Ledger status post no longer suppresses its own
  correction (#2242).** When a check-run POST raises (timeout, 5xx, dropped
  response), GitHub may still have applied it. The hub now records an
  `uncertain` marker in place of the earlier posted-status record, so a lagging
  read that still shows that earlier status cannot satisfy the compare-and-set,
  and the next settle posts the correction.
