- **The socket test suites no longer fail on a long temp path (#2293).** `tests/conftest.py` shortened pytest's temp root only on macOS, on the assumption that Linux's `/tmp` is short enough for `AF_UNIX`'s `sun_path`. That stopped being true once the pytest-tmp-guard hook began pointing `TMPDIR` at `~/.cache/pytest-<pid>` (35+ characters before pytest appends its own `pytest-of-<user>/pytest-N/<test-name>0`), and a CI checkout path is longer still. The event-bus, forwarded-trust, cloud-CI-classifier and smoke tests now get a short temp root on every non-Windows platform, which clears ~30 failures that were red on `main` and blocking every PR's release gate.
