- **CI test selection can read the two helpers that made 17 test files unownable
  (#2458).** `tests/growth_budget.py` now resolves its cache modules from
  `sys.modules` after static imports instead of a computed `import_module(name)`,
  and `scripts/ci_changes.py` builds the selector's spec at module level on a
  static path. Both helpers, and the test files that reach them, now have
  component owners, so a change inside one component no longer drags them into
  the full suite on every Python change.
