- **Paused and terminated agents run no node work; Org pane retire (#2315).** Node
  admission, claim, heartbeat and bound-attempt checks now refuse an item whose
  device owner, dispatched target or profile identity is paused or terminated,
  not only retired, with a typed 403 (`code` `agent_paused` / `agent_terminated`)
  and a `lifecycle.refused` event carrying the state. A node whose owner is paused
  stays registered and resumes claiming within a minute of a resume; the stop
  fan-out's cancel is relayed once, never repeated, and a refused claim still
  settles the owner's cancelled queued items. Node permission requests check the
  owner, target and profile identity on every backend, deny a cancel-requested
  item, and re-check both before an approval is consumed. The Control Center Org pane
  shows the `retired` state and each agent's owner of record, adds Retire (reason
  required, optional owner, confirmed) and Unretire, and hides Pause and Resume for
  a retired agent. The hub still authorizes each action; retire is operator-only.
- **Retired agents refused per request; device sign-ins revoked on retire
  (#2315).** A retired agent's bearer or device token is now refused on every
  hub request with a 403 `{"code": "agent_retired"}` (not the generic 401) and a
  rate-limited `lifecycle.refused` event. Allowed calls read the lifecycle state
  at most once per 5 s and write nothing. Retiring an agent now also deletes its
  device sign-ins (OAuth refresh and access tokens) in the same transaction, and
  unretiring does not restore them, so each device has to sign in again. A node
  whose owner is retired is refused at heartbeat, claim and receipt. The
  `retired_agent_credentials` doctor row now counts live device sign-in tokens.
- **Retirement hardening (#2315).** A web-UI cookie exchanged from a retired
  agent's bearer is refused, and `POST /api/session` mints none. Case variants
  of a fleet label (`agent-codex`) are the same identity for auth, lifecycle
  and revocation. The request path fails closed: an unreadable lifecycle state
  answers 503 `lifecycle_unavailable`, a cached "active" is trusted for 5 s
  only, and a cached retirement survives an outage. Device approval, polling and
  every OAuth token issue refuse a retired label, and a retire drops its
  outstanding approved device codes and authorization codes.
