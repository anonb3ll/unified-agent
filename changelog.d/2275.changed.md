- **Red tier follows the security boundary, not the word (#2275).** The
  unanchored `security` pattern escalated any path containing that substring, so
  a docs-only changelog fragment named with the `security` type — one shipped in
  #1343 — cost the operator an approval, while the gate code that decides what
  tests run needed none. The pattern now matches the security policy statement
  (`SECURITY.md`), a `security/` package, a `security.py` module, and any module
  or test whose name says security; `docs/**` and `changelog.d/**` prose no
  longer matches.
