- **The live-state poller no longer walks the evidence ledger every second (#2028).** While a client held a resource subscription, each poll after any commit re-rendered and diffed every evidence URI (about 630k on a long-lived hub), so the hub spent about one core-second per second polling. A poll now carries the ledger forward from the previous snapshot, renders only appended events, and diffs only the URIs that can have changed. Row revisions hash a pickle of the row instead of its `repr`, which was dominated by memory embedding blobs. A changed poll on that hub drops from about 1 s to about 0.15 s.
