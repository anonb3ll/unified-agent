- **Hub mail is scoped per tenant (#1979).** Each tenant now has its own message-id space in the mailbox index. A `message_id` that another tenant already used is accepted, and the refusal that disclosed the id's existence is gone. `message_list`, `message_inbox`, the inbox digest, replies, acks and the Messages pane conversation views see only the caller's tenant. A database from before this change has its index rebuilt once on startup; each row takes its event's tenant. The untenanted private hub behaves as before.
