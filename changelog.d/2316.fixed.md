- **A surfaces scan of `~/.codex` no longer walks Codex's plugin cache.** The configured Codex home's `.tmp` directory (`$UA_NODE_CODEX_HOME`, `$CODEX_HOME` or `~/.codex`; it holds the curated plugin clone and the marketplace caches Codex fetches) is skipped when that home is outside every git work tree. It no longer fills the 5000-file cap or reports cached plugin code as LLM-EVAL or SECRETS-KEY findings. `auth.json` and the other files in the home are still checked, and a `.codex/.tmp` inside a repository, committed or only staged, is still scanned as source.
