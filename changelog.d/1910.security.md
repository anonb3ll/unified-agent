- **Executor children no longer inherit the daemon's secrets (#1910).** Every
  native executor backend (codex, agy, claude, cursor, copilot, hermes, devin)
  used to copy the whole parent environment and drop three bearer variables,
  so provider API keys, `UA_MANAGED_SECRET_KEYS` and Slack/GitHub tokens
  reached the harness. Children now get an allowlist shared with dispatch
  (`env_allowlist.py`): process basics, hub URLs, the backend's own config
  locations and a bearer bound to the executing agent. A harness that needs an
  environment API key gets it only through `UA_EXECUTOR_ENV_PASSTHROUGH`
  scoped to that backend (`codex:OPENAI_API_KEY`).
  The isolated teamwork rehearsal explicitly opts its non-secret fixture
  settings into that passthrough so both success and negative controls cross
  the production child boundary without inheriting ambient credentials.
