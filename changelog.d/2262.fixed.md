- **Spot CI runner follow-ups (#2262).** `scripts/spot_ci.py submit` now uploads the VM startup script and executor from the commit under test, so running CI from a stale checkout no longer replaces them with an old copy. The VM's `fail_run` settles a run as `INTERNAL_ERROR` even when `state.json` is unreadable, so a watcher stops waiting. `deploy/spot-ci/provision.sh` fails early with a clear message when the project has no Cloud NAT in the VM's region, and `docs/ci-batch-verify.md` lists NAT as a setup precondition.
