- **Tests stay out of an enclosing repository (#2280).** The test fixture now sets `GIT_CEILING_DIRECTORIES` to the pytest temp root, so a test project directory that is not itself a repository no longer lets `git worktree add/list` walk up into a repository that happens to enclose the host's temp root and register stale `task-1` worktrees there. Worktree cleanup's git calls now keep a `GIT_CEILING_DIRECTORIES` the caller set; their minimal environment used to drop it, and a plain directory inside a clean, merged repository then read as disposable.
