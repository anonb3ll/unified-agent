- **Operator identity fails closed on broken worker config (#1971).** When `UA_AGENT_TOKENS` names a missing or unreadable file, the operator name and alias checks no longer raise. Every claimed operator name that needs the token check is refused, with a one-time warning. The operator name falls back to the operator's login label, which stays human. Labels pinned to OAuth or WorkOS in the hub's `$UA_HOME/service.env` now count as workers even when the process environment lacks them. This means `unified-agent init` can no longer save such a label as a human alias.
