- **The sleep pass moves a contradiction to Needs review only on the judge's
  structured answer (#2022).** The cluster judge can now return
  `self_consistent` and `conflicting_attributes`. A two-note CONTRADICTION goes
  to NEEDS_REVIEW only when the reply is exactly those fields plus verdict and
  reason, with `self_consistent: true` and `conflicting_attributes: []`; the
  report says "downgraded on structured self_consistent=true". A missing,
  malformed or duplicated field keeps CONTRADICTION, and the reason text still
  only adds the "disputes this label" marker.
  A judge reply that repeats a JSON key (such as two `verdict` fields) is now
  unparsed rather than read by its last value, so it can never become a merge
  proposal.
