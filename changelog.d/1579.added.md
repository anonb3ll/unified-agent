- **`npm run dev` can show live hub data (#1579).** With
  `UA_DEV_HUB_URL=<hub>`, the Control Center dev server proxies `/api`,
  `/healthz`, `/oauth` and `/mcp` to that hub's origin. The dev server binds to
  loopback, refuses a network-exposed `--host` while the proxy is on, and
  refuses a hub URL that carries credentials. Without the variable nothing is
  proxied. See `packages/web/README.md`.
