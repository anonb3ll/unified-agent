- **Devices-only execution for a cloud hub (#2109).** `UA_EXECUTION_LOCALITY=devices`
  is the default on Railway or with `UA_HOSTED=1`. With it, the hub never starts
  an agent itself. Control Center and scheduler dispatch route to ua-node devices
  with no local fallback. The spawner and supervisor, `pi_run_task`, the
  `claude_cli` completion leg, the agy CLI path, code-running `run_cmd`, the
  executor and `unified-agent node` refuse to run. A process-wide audit hook
  refuses any agent spawn that reaches `subprocess`/`exec`. A doctor row reports
  the setting, and a test tripwire inventories every spawn site. See
  `docs/deploy/execution-locality.md`.
- Hosted hubs refuse an explicit `local` setting. Devices-only mode also refuses
  repository Git (including configured helpers), shadowable Ruff launches and
  both native test gates. Python module detection parses only interpreter options.
