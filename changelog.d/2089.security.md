- **A malformed JSON reply from the memory judge no longer authorizes a merge (#2089).**
  A judge reply that looks like JSON (it starts with `{` or `[`, or is a code
  fence) is now read only as one strict JSON object; a malformed, too deeply
  nested or incomplete one makes the cluster unparsed, with no merge proposal,
  supersede or apply command, instead of being rescued by the plain-text
  `VERDICT:` pattern. The plain-text form still works for genuinely non-JSON
  replies, whose `VERDICT:` line must now open a line. The Codex leg also
  reports a reply with duplicate JSON keys as a schema mismatch.
