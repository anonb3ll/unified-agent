- **Affected-test selection flags a spawn fetched through `getattr` with a
  splatted default (#2276).** `getattr(subprocess, "run", *opts)(...)` and the
  `**kw` form were not read as a process spawn, and the default was never
  visited, so the call was silently dropped. It now marks the file unresolved
  ("getattr() of a default built at run time"), which runs it on every Python
  change.
