- Supervised long commands on a ua-node (#2413). `coordination_manage("node_command_start", {node, argv, cwd})` runs an argv list (never a shell string) on a node, behind the existing node-dispatch approval gate, so a long test or build keeps running when the session that started it dies. When it ends, the owner label gets exactly one `hub-node` message with the exit code, duration and log path; a later session of the same agent can `node_command_adopt` it while it runs, and `node_command_status` reads it. Each claim carries a fence token, and a completion from a writer without it is refused (`409 stale_fence`, audited). Off by default: a node runs a command only when `command` is in `UA_NODE_BACKENDS` and `argv[0]` is in `UA_NODE_COMMANDS`. New doctor row `command_items_unsettled`.
