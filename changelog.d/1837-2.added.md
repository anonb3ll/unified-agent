- **Claude Code sessions now report their usage automatically (#1837).** A `PostToolUse`/`SessionEnd` hook (`scripts/hook_usage_report.py`) remembers the run a `task_claim` opens and, when `task_update` ends it or the session ends, runs `ua-usage --report` in the background to record the session's measured tokens on that run through the hub. The new `--report --task --run --agent` mode posts the measurement as `task_claim(usage_only=True)` under the run's own actor. Billing is still never inferred, and a missed report leaves the run unknown-cost as before.
