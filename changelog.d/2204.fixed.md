- **The audit gates check a worktree's own code (#2204).** The pre-commit hook
  and the agent pre-push gate ran the shared venv's `unified-agent-audit`,
  an editable install of one checkout, so a linked worktree was audited with
  that checkout's rules. They now run `scripts/run_audit.py`, which imports
  the committing checkout's `src` and refuses to run if it resolves anywhere
  else. Re-run `./scripts/install-hooks.sh` to refresh an installed hook.
