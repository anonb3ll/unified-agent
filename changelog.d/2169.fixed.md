- The redactor follows a commented-out JS or YAML string across a backslash line continuation at any break that ends a comment (LF, CRLF, CR, U+2028, U+2029, NEL), so a private JWK member such as `dp` whose key or type key is split over a Python `#` comment break is masked by `redact`, `private_members`, the audit secret check and the public relay, including identity-escaped keys in a plain comment and continuations at the first or last character of a quoted key or type value.
