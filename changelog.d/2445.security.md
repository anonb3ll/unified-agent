- **The JWK redactor masks unread residue inside keys it has typed (#2445).** When the
  JSON scan reads an object's `kty` but not a private member's name (a computed key,
  `"d" = ...`, `"d" => ...`, a full-width colon, a pair array), the coarse fallback now
  masks long mixed-alphabet runs inside that object, except plainly written public
  parameters (`n`, `e`, `x`, `y`, `crv`, `kid`, `alg`, `use`, `x5t`, `x5u`, `x5c`,
  `key_ops`). A public JWKS stays readable; other ids and metadata inside a typed key
  object are now masked in logs and public replies. The secrets audit is unchanged.
