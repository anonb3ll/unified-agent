- **Executor runs now count their real spend against budgets (#1917).** The
  executor parses usage from Claude Code (tokens and `total_cost_usd`), Codex
  and Agy (tokens) output and reports cumulative fenced run accounting, so a budget
  counts what a run cost instead of only `run_reserve_usd`, from the moment it
  is reported rather than when review closes the task. The same tokens and cost
  feed the run's autonomous cycle limits. A `task_claim` renewal carrying
  `run_usage` now returns `budget_warnings` past the warning threshold and
  `budget_stop` once a `block` budget is exceeded. `budget_status` adds
  `open_run_cost_usd`.

  Late authenticated usage survives expiry, cancellation and takeover without
  changing run lifecycle; retries retain earlier spend and stop on blocking
  budgets. Run/cycle snapshots replay durably and each cycle attempt counts once.
  Mixed priced/unpriced attempts retain known USD plus the unknown-cost reserve,
  with explicit sticky `cost_complete: false` accounting metadata. Persistence
  failures stop retries and retain lifecycle cleanup with a recovery failure.
