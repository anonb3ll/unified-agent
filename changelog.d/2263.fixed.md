- **A committed MCP credential in a deeper nested repository is reported (#2263).**
  When one repository sat at an enclosing repository's MCP config path (for
  example `a/config/mcp_config.json`, where `a/config` is its own repository),
  the audit asked the enclosing repository's index whether the file was
  tracked, was told it was not, and dropped the finding. Each config is now
  judged by the repository that holds it, including when it is only staged.
