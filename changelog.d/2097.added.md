- **Memory confidence and versions (#2097).** `memory_feedback` counts now form a
  per-note Beta posterior (helpful +1 alpha; not_helpful +1, stale +0.5, wrong +2
  beta). Each open `contradicts` link against a note lowers its effective
  confidence at read time, and that value is the confidence input of the search
  prior inside the unchanged [0.8, 1.2] clamp. `memory_get`, `memory_feedback`
  and search explanations report `confidence_posterior`. A trigger records each
  note's earlier content and tags in `memory_versions` on every change, whatever
  path made it (newest 50 kept, index notes excluded), and
  `memory_get(include_versions=True)` returns them newest first; with `as_of`,
  only the states already replaced by then (`recorded_at`). A hard delete
  erases a note's versions.
