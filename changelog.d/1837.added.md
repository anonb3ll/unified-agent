- **Runs now carry measured usage and who paid for it (#1837).** Executor runs on Claude Code and Codex record `billing` (`subscription` or `api`) from the CLI's own `auth status` / `login status`, asked under the child's environment right after the run; a Codex run counts as subscription only when its own session recorded the OpenAI provider, and a resumed Codex run is left unknown. A Max or ChatGPT login is no longer charged to a dollar budget at API prices, and a subscription run charges its autonomous cycle tokens but no dollars. The new `ua-usage` command prints the `run_usage` of an interactive Claude Code or Codex session for one run's window, from the harness's local session store, for agents to pass to `task_update` when they finish; previously every interactive run finished unknown-cost. It never infers `billing` (pass `--billing` to state it), and no price is ever derived from tokens.
