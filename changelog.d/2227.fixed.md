- **Identity-escaped JWK keys are masked in plain comments and continued live source (#2227).** A key such as `"\d\p"` (which JS reads as `dp`) in a plain `#` comment, or in live source whose `kty` key or value is split by a line continuation, no longer leaks its private value to the redactor, the secrets audit or the public-relay gate. Live source without such JS-only evidence keeps its Python meaning.
