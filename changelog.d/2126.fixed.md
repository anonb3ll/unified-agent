- **A JWK in a YAML flow mapping whose type continues across lines is redacted
  (#2126).** In a YAML double-quoted scalar a backslash before a line break
  removes the break and the next line's indentation, so
  `{kty: "oct\<line break>    ", k: ...}` is a symmetric key. The redactor read
  the type with Python string rules, kept the indentation, and masked nothing.
  It now also reads a double-quoted type or member name as YAML (LF, CRLF, CR
  and NEL breaks, any number of continuations, YAML escapes), so the private
  members are masked and reported by the secrets audit and the public-reply
  gate. JSON objects keep their existing decision byte for byte.
