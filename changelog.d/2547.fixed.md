- Session mail no longer strands unseen (#2547). A message sent with `to_session` to a session the reaper marked abandoned, or to one past the live window, now goes to the agent label, and the send result says so in `session_fallback`. Unread session mail left in a session that has ended is reported once by the queue-hygiene pass: the recipient label gets one notice per ended session listing the message ids and how to read them, and each sender gets one notice; no body is quoted and nothing is re-sent (`UA_MESSAGE_STRANDED`, default `notify`). Such mail shows `terminal: stranded` and is not dead-lettered as well. Reading another session's mailbox with `session_id` no longer revives a session the reaper ended.
