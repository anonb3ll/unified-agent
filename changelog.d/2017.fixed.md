- **A ua-node turn summary no longer scans the whole node event log (#2017).**
  Counting a finished turn's ACP events filtered every `agent.node` event with
  `json_extract`, so each turn end cost more as the log grew. A partial
  expression index on the event's `item_id` and `turn_id`, limited to the
  node channel, now serves that query. It is created on the next start with no
  schema version change; the counts are unchanged.
