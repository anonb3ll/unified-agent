- **Control Center launches are safe to retry (task #2501).** `POST /api/action/dispatch`, `/dispatch-stack` and `/node-session` (start and restart) accept an optional `Idempotency-Key`: the hub records the attempt before starting anything, a repeat with the same key and request returns the first answer and never starts a second job, the same key with another request is a 409, a concurrent repeat is a 409 `launch_in_progress`, and a repeat after an approval continues the same delegation or queue item. `GET /api/launch-attempts/{key}` reports an attempt (`unknown`, `in_progress`, `parked`, `started`, `failed`) to its own caller, and an attempt left in progress by a hub restart is reconciled from what it created. `GET /api/sessions/{id}` now carries the session's wake state, and recent ua-node items carry `agent_session_id`, the hub registry session id. Without the header the routes behave as before.
