- **Worktree cleanup sees a program run through a `PATH=` override, and the
  `ps` scan is faster (#2199).** `env PATH=<checkout>/bin tool`, `sudo
  PATH=... tool`, `sh -c 'PATH=... tool'` and `export PATH=...; tool` now
  resolve `tool` on the assigned PATH as well as the process PATH, so the
  checkout counts as in use. On macOS, each `ps -E` environment word (such as
  a `;`-heavy `LS_COLORS`) is read once per scan instead of on every line, and
  PATH lookups no longer rebuild the directory list on each call. A
  600-process listing with 24-variable environments takes 0.14 s of CPU
  instead of 2.07 s.
