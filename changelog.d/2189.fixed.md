- **Cloud Build CI timeouts (#2189).** The build timeout rises from 3600 s to
  5400 s: the slowest test shard now runs close to an hour, and one batch lost
  its full verification to the old limit. `scripts/cloud-ci.sh` no longer
  counts queue time against the run: builds run one at a time, so a queued
  build waited out most of the old fixed 4500 s budget. Queueing now has its
  own 3 h bound (and `queueTtl: 10800s`, since Cloud Build expires a queued
  build after 1 h by default), and the run deadline (6300 s) starts only when
  the build is seen `WORKING`.
