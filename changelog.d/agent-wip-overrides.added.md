- **Per-agent WIP cap overrides (`UA_AGENT_WIP_OVERRIDES`).** A comma-separated `label:max` list sets a different concurrent `doing` cap for named agents, such as a lead agent that claims for several workers, while every other agent keeps `UA_AGENT_WIP_MAX`. `task_claim`, `task_update`, team-spec plans, queue pressure and the board report each agent's effective cap. Fleet and lane caps are unchanged.
