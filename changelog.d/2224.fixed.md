- The redactor reads a `//` line comment body as comment prose, like a `#` body, so an orphan quote in it no longer hides a braced (`\u{64}`) or identity-escaped (`\d\p`) private JWK key, with or without a line continuation. Comment recovery also treats `//` as a payload separator and accepts JS identity escapes in key and type spellings, and `private_members` drops only exact duplicate members (and a copy without an audit span when an identical member has one), so a placeholder never displaces a real private value (#2224, #2236).
