- **The JWK redactor masks key syntaxes it cannot parse, and its grammar stops growing (#2441).**
  A new coarse fallback (`telemetry/jwk_fallback.py`) masks long, mixed-alphabet base64url
  runs within 4096 characters of a `kty` marker when no existing rule decided that text.
  Private keys written as TOML, HTTP headers, enum-typed calls or env files were logged
  in clear before and are masked now. Objects the JSON scan decides are unchanged, so a
  public JWKS stays readable. `private_members` runs the fallback by default, so the log
  redactor and the public-relay gate get it; the secrets audit opts out. `docs/security.md` ("JWK redaction scope") states what is
  and is not promised. `scripts/test_budget.py` pins the grammar modules' line counts:
  growing one needs a `Redaction-Grammar: <evidence>` commit trailer.
