- **Idle-session wakes need the operator's grant, per session (#2050).** A
  session's own `wake: true` registration is now only a request, because the
  hook and the agent share the harness bearer. Wakes start only once the human
  operator grants that hub session from the Control Center Sessions pane
  (`POST /api/sessions/{id}/wake-grant`, `{grant: bool}`); agent bearers and
  session credentials get 403. The grant is bound to the session id: it survives
  the session registering again, a new session needs a new grant, and the
  operator can revoke it. Every grant and revoke is on the event log
  (`agent.wake.grant`), and `system_doctor`'s `agent_wake` row lists sessions
  awaiting a grant.
