- A retry that adopts another attempt's in-flight approval no longer returns
  that pass if the retry itself fails; only the attempt that consumed it may.
- A request whose approval was later spent by an identical request from
  another principal now asks for a fresh approval instead of failing as
  "superseded" on every retry.
- A task update admitted only as a committed replay refuses to write when its
  receipt is missing, and the replay preflight closes its connection.
