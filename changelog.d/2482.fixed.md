- **Interrupted work can no longer be picked up from the queue (#2482).** When
  the lease reaper found a claim whose owner's run never recorded a finish, it
  blocked and unclaimed the task, but a delegation already queued for that
  task stayed claimable, so the executor could start blocked, unowned work.
  That state is now a hold that every autonomous admission path checks:
  `delegate_claim` returns `claimed: false` with `held`, `delegate_list` marks
  the pending row `held` and the executor skips it, and approved dispatch,
  `dispatch_resume`, node dispatch and a `task_claim` that rides a queued
  delegation are refused. A claim by an agent with no delegation queued for
  the task resumes the work, reopening the task lets queued work run, and
  closing it ends the hold.
