- **`run_cmd` no longer lets an allowlisted program run code without approval
  (#1904).** `run_cmd_check` returned a clean verdict for a dozen ways to run an
  arbitrary program through `git` or `sort`, so the forced approval gate never
  fired. Among them: `git config alias.x '!cmd'` followed by `git x`,
  `git -c include.path=...`, `git grep -O<cmd>`, `git rebase -x`,
  `sort --compress-program`, and `find -fprint` or `sort -o` into `.git/hooks`.
  These now raise `allowlist-bypass`. `git -c` checks against a safe-key
  allowlist instead of a short denylist, and a value attached to a short option
  (`git -C/etc`) is checked for a workspace escape. `sort -o` now counts as
  mutating.
