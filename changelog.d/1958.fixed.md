- **The hub no longer freezes for seconds at a time (#1958).** The MCP
  live-state poller rehashed every served row on the event loop after each
  commit (1-2 s per poll on the Mac hub, 4.6 s for a baseline), so health
  checks, executor polls and tool calls queued behind it and timed out. It now
  polls in a worker thread, skips work while nobody subscribes, and still
  publishes every commit made while idle once a listener arrives.
