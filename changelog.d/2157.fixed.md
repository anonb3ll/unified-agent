- **The daily surfaces audit no longer fails on agent session transcripts, and an
  old accepted risk no longer hides a new finding class (#2157).** Codex,
  Claude Code, Gemini CLI and Hermes session logs and memories are local agent
  history, not source: a JWK private-member match there is now `low` with the
  message "in an agent session transcript, not source control", while
  vendor-shaped keys stay `high` and credential-store checks (`auth.json`,
  `SECRETS-STORE-PERMS`) are unchanged. Audit triage markers now carry a finding
  class (`[audit-triage: <root>:<rule>:<class>]`, the class being the first path
  segment under the root), so an `[accepted-risk]` task covers only the class it
  was written for. Existing tasks keep covering the classes their notes list,
  so nothing already accepted is refiled.
