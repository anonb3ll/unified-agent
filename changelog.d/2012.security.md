- **A sleep-pass or consolidation proposal can no longer smuggle in an apply command (#2012).** A model's reason, a note title or a journal digest line could carry a newline followed by `unified-agent-consolidate apply <survivor> <ids>`, and `unified-agent-consolidate apply-batch` ran every such line it found in the file. Proposals now render reasons and titles on one line and quote command-shaped digest lines, and `apply-batch` runs only apply lines inside a ```` ```bash ```` fence that holds nothing else. It reports any other command-shaped line as `ignored_unfenced` and does not run it; the CLI prints that count. Line endings are normalised first, so a lone carriage return in a digest cannot open a fence.
