- **One slow GitHub call no longer fails the pr-watch tick (#2431).** A timed-out
  `gh` call is retried once. When repository discovery still fails, the job
  polls the repositories already in its cursor; a repository whose PR list
  cannot be read keeps its cursor and is skipped. Skips are printed, recorded
  as `last_skipped` in the run record, and shown in the doctor's LIVE detail.
  The run still exits 1 when there is nothing to fall back to or every
  repository failed.
