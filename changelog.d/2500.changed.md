- **The operator's own write no longer dead-ends on approval for two actions.**
  On a hub with one human an approval needs a different person, so a Control
  Center write the operator made himself could never be approved. `task_delete`
  and the LangGraph workflow run (`langgraph_governed_call`) now record the
  operator's own verified submission as a pass instead, with the approval row,
  its reason and an `agent.approval.self_approval` ledger event naming the tool,
  the operator and why. The pass is one-shot and consumed through the same
  compare-and-swap as every other pass. Minting and consumption commit together,
  so another caller cannot spend the operator's pass between those steps.
  Separation of duties is unchanged for
  work-product release, config revision commit/rollback, harness config apply and
  org proposal apply, and an agent credential can never reach the pass by naming
  the operator: the decision is keyed off the transport-verified identity.
