- **Changelog fragments (#1808).** Each PR now adds one `changelog.d/<id>.<type>.md`
  fragment instead of editing `CHANGELOG.md`, so a batch of squash merges no longer
  conflicts on the changelog. `scripts/changelog_assemble.py` validates fragments
  (`--check`), previews the result (`--dry-run`) and, at release, folds them under
  `## [Unreleased]` in Keep a Changelog order and deletes them. Convention in
  `changelog.d/README.md`.
