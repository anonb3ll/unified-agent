- `scripts/agy_teardown_canary.sh` reports the silent background-task loss of agy 1.2.7 and 1.2.14 as `KILLED ... teardown=0 silent=1` (exit 1) instead of `ERROR` (exit 2), when agy exited 0, its stream shows the canary's `run_command` step `DONE`, and the marker is still missing after a bounded wait (`UA_AGY_CANARY_MARKER_WAIT_S`, default 10 s). `ERROR` now means a real setup or invocation failure (#1791). The silent verdict also requires the last stream-json `result` event to report `SUCCESS` and the DONE `run_command` step's `CommandLine` to be exactly the canary launch command, so an agy-reported failure or a command that only mentions the marker stays `ERROR`; the wait setting is read as decimal (`08` is 8 s) and capped at five digits.
