- **Stale-worktree cleanup keeps live deploy checkouts (#2174).** A `release-*` or
  `rollback-*` checkout, or one a running process works in or runs code from, is no
  longer reported stale after seven idle days, so `cleanup_stale_worktrees` cannot
  remove the code of a running hub, node or executor. The doctor's `stale_worktrees`
  row lists such checkouts as kept.
