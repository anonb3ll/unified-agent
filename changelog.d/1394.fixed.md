- **A desktop executor places a hub Git run under `~/dev` or refuses it (#1394).**
  The recorded hub worktree is re-rooted on this host, and the child does not
  start in the workspace root or in a repository above that bound. Clone the
  project at `~/dev/<repo>` and retry. An existing task worktree is reused
  only when its HEAD and branch match the hub attestation; a new worktree can
  start at that SHA while the project checkout stays put. A checkout with no
  `origin` remote is still accepted, and a remote that names a different repo
  is not. Review of desktop-local work skips an unsafe branch name instead of
  holding it. A surfaces scan skips the Codex home's plugin cache when that
  home is outside a git work tree, and an RSA `oth` array treats only `r`,
  `d`, and `t` as private.
