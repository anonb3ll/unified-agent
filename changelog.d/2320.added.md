- **The `unified-agent/review-head` check now has a producer (#2320).** The
  Approval Ledger poll publishes it at every open PR head, including the
  markdown-only PRs CI skips. A read at the head, a covering delta read or a
  clean delta is `success`; no recorded read is `action_required`, never green;
  a head that moved off what was read is `failure` until a covering read lands.
  One check per head, updated in place, with no GitHub write when the answer has
  not changed. A compare or post that fails publishes nothing and retries. In
  user-token mode the check is a commit status under its own context, and the
  merge receipt reads it there. `UA_REVIEW_HEAD_CHECK=0` turns it off.
