- **The evidence ledger now records what a tool call did, not only that it ran
  (#1907).** Each `agent.gateway.decision` event carries `args_sha256`, a
  canonical-JSON digest of the supplied arguments. `run_cmd`, `fs_write`,
  `vault_write`, `memory_save`, the task, delegation and Git mutators also get
  a redacted, size-capped `args_summary` (argv and cwd, or path plus content
  sha256 and byte length; content itself is never stored). A mutating call
  whose event cannot be written now fails with a ToolError instead of
  succeeding unaudited; read-only calls stay best-effort.
