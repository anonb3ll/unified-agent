- **Chunked embeddings for long memory notes (#2182).** A note longer than
  about 2,000 characters now keeps overlapping windows of about 400 tokens
  (at most 16) in `memory_chunks`, beside the existing truncated vector.
  Semantic search scores the note by the best of the two. Short notes are
  unchanged. `UA_MEMORY_CHUNK_EMBEDDINGS` defaults on after a 30-question
  LongMemEval sample (5 per type, seed 2145) rose from 26/30 to 27/30 strict
  recall@5 with no question scoring worse; set it to `0` to keep only the
  single vector. Deleting a note deletes its windows, including the vec0
  mirror. Superseding a note keeps them, so a historical search can still
  score a fact that lived only in a later window; default search still skips
  superseded notes. Existing long notes are filled in bounded batches after
  startup.
