- **Redaction covers more private-key shapes and no longer stalls on long hyphenated text (#1994).** `redact_sensitive_content` now removes a whole PuTTY `.ppk` key: the header, fields, `Public-Lines` and `Private-Lines` bodies, and `Private-MAC`, where before only the header line went. It also removes the values of a JWK's private members `d`, `p`, `q`, `dp`, `dq` and `qi`, keeping the member names. A private key that has lost its END line is now removed in more forms: flattened onto one line, on the header's own line, double-JSON-escaped, `\u000a`-escaped, broken with `<br>` or `&#10;`, split by a lone CR, in a Python repr list, or JSON-escaped with `\/`. The same holds when its header is a lowercase `proc-type:` or when its short last line is followed by ordinary text. The credential-in-URL pattern is now linear: 100 KB of `a-a-a-...` takes 0.02 s instead of 32 s.
