# PR inventory tier (task #2440, epic #2437 phase K5a).
#
# The `gates` job runs these on every pull request, before the merge batch:
#   uv run pytest $(this list) -q -m "not embeddings"
# Each entry freezes a central registry that a change anywhere can break without
# touching the code the test imports: a table without a tenancy class, an import
# reference missing from tools/export.py, a module missing from layers.toml, an
# unregistered route or tool. Batch and nightly shards run the same files.
#
# One entry per line: a test file or a pytest node id. `#` starts a comment.
# Every file in affected_tests.ALWAYS_RUN must appear here (whole or by node id);
# tests/test_ci_workflow_parity.py checks that and that each entry exists.
# Budget: the whole tier stays under about 90 s on a 4-core desktop, so `gates`
# grows by at most 3 minutes. Time a candidate file alone before adding it, and
# never add a test marked `embeddings`. See docs/ci-batch-verify.md#inventory-tier.
