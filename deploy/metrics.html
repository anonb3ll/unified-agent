Connection Troubleshooting

Could not reach the unified-agent MCP hub. Since the dashboard is loaded as a local file (file://), browser CORS policies block connections to localhost by default.

  • Option A (Recommended): Serve via local HTTP

    Start a local server in the workspace root and open that address instead:

    python3 -m http.server -d ~/agent-workspace 8000

    Then open: http://localhost:8000/metrics.html

  • Option B: Use a CORS extension

    Install a browser extension like "CORS Everywhere" (Firefox) or "Allow CORS" (Chrome/Firefox) and toggle it ON to permit local file access.
